# Projet Fil Rouge — Portfolio Solène Avril

Reproduction responsive d'un portfolio photographique à partir de la maquette fournie en annexe.

## Fichiers

- `index.html` : structure HTML sémantique.
- `style.css` : mise en page, galerie CSS Grid et media queries.
- `script.js` : mélange aléatoire des positions des photos à chaque rechargement et filtres interactifs par catégorie.

## Technologies et ressources

- HTML5 et CSS3
- JavaScript natif
- Google Fonts : Yeseva One et Montserrat
- Font Awesome
- Lorem Picsum pour les images de démonstration

## Lancer le projet dans VS Code

1. Décompresser le dossier.
2. Ouvrir le dossier dans Visual Studio Code.
3. Installer l'extension Live Server.
4. Faire un clic droit sur `index.html`.
5. Choisir **Open with Live Server**.

Une connexion Internet est nécessaire pour charger les polices, les icônes et les images distantes.

## Vérifications avant le dépôt

- HTML : https://validator.w3.org/
- CSS : https://jigsaw.w3.org/css-validator/

Les images Lorem Picsum sont des images de démonstration aléatoires : vérifier leur pertinence visuelle et les remplacer si besoin avant la remise finale.

## Publication GitHub Pages

1. Créer un dépôt GitHub public.
2. Ajouter les trois fichiers du projet et ce README.
3. Effectuer un commit.
4. Dans le dépôt : **Settings > Pages**.
5. Choisir **Deploy from a branch**, branche `main`, dossier `/ (root)`.
6. Enregistrer et attendre la publication du site.
